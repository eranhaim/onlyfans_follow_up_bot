📁 כל הקבצים — מה כל אחד עושה?

⚙️ config.py
כל ה-settings של האפליקציה — מה שנקרא מקובץ .env
סיסמאות, API keys, URLs של הדאטה-בייסים
🚀 main.py
נקודת הכניסה — מה קורה כשהשרת עולה
מאתחל DB, מפעיל scheduler, מתחבר לTelegram
🗄️ database.py
הגדרת כל הטבלאות בPostgres
חשבונות, שיחות, stages, וידאוים, לוג הודעות
🍃 mongo.py
שמירה וקריאה של היסטוריית שיחות מMongoDB
כל הודעה שנשלחה/התקבלה נשמרת פה לGPT
🌐 routes.py
כל ה-API endpoints — מה שה-frontend קורא
login, stages, videos, conversations, telegram
📱 telegram_service.py
הלב של הבוט — מתחבר לTelegram ושולח הודעות
מקבל הודעות נכנסות, מריץ follow-ups
⏰ scheduler.py
טיימר שרץ כל 5 דקות ובודק מי צריך follow-up
כמו cron job — רץ ברקע כל הזמן
🧠 llm_service.py
מדבר עם GPT ומקבל הודעת follow-up
שולח system prompt + היסטוריה, מקבל JSON עם הודעה ווידאו
☁️ s3_service.py
מעלה/מוריד וידאוים מAWS S3
כשמחליטים לשלוח וידאו, הוא מוריד מS3 ושולח בTelegram
📋 schemas.py
הגדרת צורת הנתונים שנכנסים ויוצאים מה-API
וולידציה — מה מותר לשלוח לAPI ומה חוזר

🗄️ מה שמור בPostgres — הטבלאות

📱 telegram_accounts
id (מזהה)
name (שם המודל)
phone (מספר טלפון)
session_string (session שמור)
is_connected (מחובר?)
💬 conversations
id (מזהה)
telegram_user_id (מי הלקוח)
steps_sent (כמה follow-ups נשלחו)
last_user_message_at (מתי כתב לאחרונה)
opted_out (ביקש להפסיק)
📋 follow_up_stages
id (מזהה)
position (סדר — stage 1, 2, 3...)
delay_hours (כמה שעות לחכות)
system_prompt (הוראות לGPT)
is_active (פעיל?)
🎬 videos
id (מזהה)
s3_key (נתיב בAWS)
filename (שם הקובץ)
tags (תגיות)
description (תיאור)
📝 sent_message_logs
id (מזהה)
message_text (הטקסט שנשלח)
sent_at (מתי)
success (הצליח?)
error (שגיאה אם נכשל)
🍃 MongoDB — chat_messages
account_id
telegram_user_id
role (user / assistant)
content (תוכן ההודעה)
timestamp
💡 MongoDB שומר את היסטוריית השיחה — כדי שGPT יוכל לראות מה נאמר קודם ולכתוב follow-up שמתאים להקשר

🚀 מה קורה כשהשרת עולה (main.py)

1️⃣
init_db()
יוצר טבלאות בPostgres אם לא קיימות
↓
2️⃣
init_mongo()
יוצר indexes בMongoDB
↓
3️⃣
seed_defaults()
אם אין חשבונות + יש session בenv — יוצר חשבון ראשון
↓
4️⃣
start_scheduler()
מפעיל טיימר — כל 5 דקות בודק follow-ups
↓
5️⃣
connect_all()
מתחבר לכל חשבונות Telegram

🔑 ה-.env — מה צריך להיות שם

ADMIN_PASSWORD — סיסמת הכניסה לpanel TELEGRAM_API_ID + TELEGRAM_API_HASH — מtelegram.org OPENAI_API_KEY — בלי זה GPT לא עובד AWS_ACCESS_KEY_ID + AWS_SECRET — בלי זה S3 לא עובד DATABASE_URL + MONGODB_URL — כתובות הדאטה-בייסים
💡 אם OPENAI_API_KEY חסר — הבוט עדיין עובד, אבל שולח "Hey! 💕" לכולם במקום הודעה מותאמת
